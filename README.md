# Sistema de Gestão de Currículos

Aplicação web desenvolvida com Next.js para cadastro e gerenciamento de currículos.

## 🚀 Tecnologias
- Next.js (App Router)
- Tailwind CSS
- shadcn/ui
- React Hook Form + Yup
- Sonner
- React Icons
- React iMask

## 📄 Funcionalidades
- Landing page com apresentação do sistema
- Lista de currículos com busca em tempo real
- Cadastro completo com validação e máscaras
- Campos dinâmicos para experiências e formações
- Upload fake de foto de perfil
- Feedback visual com toasts

## ▶️ Como rodar
```bash
npm install
npm run dev
```
Acesse http://localhost:3000
